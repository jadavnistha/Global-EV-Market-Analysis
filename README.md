# 🚗 EV Market Analytics Dashboard

## 📌 Project Overview

This project analyzes the global and Indian Electric Vehicle (EV) market using Excel, SQL, Python, and Power BI. The dashboard provides interactive insights into EV sales trends, top manufacturers, vehicle registrations, and regional performance to support data-driven decision-making.

---

## 🎯 Objectives

- Analyze global EV sales trends (2010–2024)
- Identify top EV manufacturers
- Study EV registrations by vehicle class
- Compare regional EV performance
- Build an interactive Power BI dashboard

---

## 🛠️ Tech Stack

- Microsoft Excel
- SQL (MySQL)
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI


## 📊 Dashboard Features

- KPI Cards for Total EV Sales, EV Makers, Regions, and Countries
- EV Sales Trend Analysis (2010–2024)
- Top 10 EV Manufacturers
- Top 10 Countries by EV Sales
- EV Registration by Vehicle Class
- India & Global Market Insights
- Interactive Filters (Region/Country and Year)

---

## 🐍 Python Visualizations

- Global EV Sales Trend (Line Chart)
- Top 10 EV Manufacturers (Horizontal Bar Chart)
- EV Registration by Vehicle Class (Donut Chart)
- Top 10 Countries by EV Sales (Bar Chart)
- Top States by EV Manufacturers (Bar Chart)

---

## 💡 Key Insights

- Global EV adoption has grown rapidly over the last decade.
- A few leading manufacturers dominate the EV market.
- Passenger vehicles account for a significant share of EV registrations.
- EV adoption varies considerably across countries and regions.
